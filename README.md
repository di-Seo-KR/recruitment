# PM 업무관리 대시보드 (Excel)

PM들이 쓰는 To Do / Doing / Done 칸반 방식의 일정관리 툴입니다.
**`PM_업무관리_대시보드.xlsx`** 파일을 내려받아 바로 사용하세요.

## 구성

| 시트 | 역할 |
|---|---|
| 📊 대시보드 | KPI 타일(전체·To Do·Doing·Done·완료율·지연) + 상태/우선순위/담당자별 현황 및 차트 — 전부 자동 계산 |
| 🗂 칸반보드 | To Do / Doing / Done 카드 보드 — 상태를 바꾸면 자동 갱신 |
| ✏️ 업무목록 | 실제 입력 시트 — 드롭다운, D-Day 자동 계산, 지연 업무 자동 강조 |
| ⚙️ 설정 | 담당자 드롭다운 목록 관리 (최대 10명) |
| 📖 사용법 | 파일 안에 포함된 상세 사용 안내 |

## 주요 기능

- 상태(To Do/Doing/Done)·우선순위(높음/중간/낮음)·담당자 드롭다운 입력
- D-Day 자동 계산: `D-3`, `🔔 오늘 마감`, `⚠ n일 지연`, `✔ 완료`
- 마감 지연 업무는 행 전체가 붉게, 완료 업무는 회색 처리
- 진행률(0~100%) 데이터 막대 표시
- 업무 200행, 칸반 열당 30개 카드까지 자동 서식/수식 적용
- 예시 업무 12건 포함 (지우고 사용)

## 다시 생성하기

```bash
pip install openpyxl
python3 generate_pm_dashboard.py   # → PM_업무관리_대시보드.xlsx
```

수식은 Excel 2016 이상과 호환되는 함수만 사용합니다
(IF, COUNTIF, COUNTIFS, COUNTA, INDEX, MATCH, IFERROR, TEXT, TODAY).
